# سامانه هوشمند مدیریت ناوگان و ثبت کارکرد رانندگان (هلدینگ انتخاب)
### Arman Fleet Management System - Entekhab Industrial Group

این پروژه یک اپلیکیشن بومی و پیشرفته اندروید است که با استفاده از **Kotlin** و **Jetpack Compose** برای مدیریت هوشمند سفرها، مأموریت‌ها، تعرفه‌گذاری مصوب و تسویه مالی ناوگان ترابری هلدینگ انتخاب توسعه داده شده است.

---

## 📱 امکانات و بخش‌های اصلی سامانه

### ۱. پنل رانندگان (Driver Workspace)
- **ثبت سریع سفر و مأموریت:** انتخاب مبدأ و مقصد، تشخیص هوشمند کد مسیر و استخراج خودکار تعرفه ریالی مصوب.
- **پشتیبانی از تاریخ شمسی:** ثبت سفر برای تاریخ جاری یا روزهای گذشته با اعمال نرخ معتبر همان تاریخ.
- **سفر رفت و برگشت خودکار:** قابلیت ثبت تک‌کلیکه مسیر برگشت بدون ورود اطلاعات تکراری.
- **محاسبه آنی درآمد:** نمایش جمع سفرهای روز، کارکرد ماه جاری و درآمد خالص/ناخالص به ریال و تومان.
- **ارسال به کارتابل مدیر:** ارسال کارکرد روزانه به مدیریت جهت بررسی و قفل شدن ویرایش پس از تأیید.

### ۲. پنل مدیریت ناوگان (Admin & Fleet Management)
- **کارتابل تأیید کارکرد (Approval Inbox):** بررسی وضعیت کارکردها، فیلتر (در انتظار، تأیید شده، رد شده)، تأیید نهایی یا رد با درج علت.
- **مدیریت تعرفه‌ها و مسیرها:** ثبت و ویرایش مسیرهای ترابری به همراه تاریخ اجرای تعرفه و حفظ تاریخچه نرخ‌ها.
- **مدیریت پرونده رانندگان:** ثبت و ویرایش مشخصات پرسنلی، خودرو، شماره پلاک و وضعیت فعالیت.
- **گزارشات تسویه مالی ماهانه:** محاسبه جمع کارکرد، کسورات قانونی و تعیین وضعیت پرداخت.
- **لاگ امنیتی (Audit Logs):** ثبت تمام تراکنش‌ها و تغییرات نرخ‌ها به همراه نام اپراتور و زمان دقیق.

## 🛠 فناوری‌ها و معماری (Tech Stack)

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material Design 3 - RTL)
- **Architecture:** MVVM (Model-View-ViewModel) + Clean Architecture
- **Local Persistence:** Room Database (SQLite Engine)
- **Asynchronous Flow:** Kotlin Coroutines & StateFlow
- **Design System:** Corporate Theme (Navy Blue & Gold)

## 🚀 راهنمای اجرا در Android Studio و گیت‌هاب

1. **کلون یا دانلود پروژه:**
   پروژه را از گیت‌هاب کلون کرده یا فایل ZIP آن را اکسترکت کنید.
2. **باز کردن در Android Studio:**
   نرم‌افزار اندروید استودیو را باز کرده و پوشه ریشه پروژه را باز (Open) کنید.
3. **همگام‌سازی گریدل (Gradle Sync):**
   صبر کنید تا فرآیند دانلود وابستگی‌ها و همگام‌سازی به پایان برسد.
4. **اجرا (Run):**
   یک دستگاه اندروید یا شبیه‌ساز (Emulator) انتخاب کرده و دکمه **Run (Shift + F10)** را بزنید.
5. **تولید خروجی APK:**
   از منوی بالا به مسیر `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)` بروید.
